## 👨‍💻 About Me

I'm a **Computer Science student from Egypt** and a **Software Engineer Intern at Nancy AI**, working remotely with a Netherlands-based team.

My main focus is backend engineering: building maintainable, scalable systems with **C#/.NET and Go**, while continuously improving my knowledge of distributed systems, cloud infrastructure, and software architecture.

- 🔧 Building backend services with **C#/.NET, Go, PostgreSQL, MongoDB, and RabbitMQ**
- 🏗️ Interested in **Clean Architecture, SOLID, Domain-Driven Design, and distributed systems**
- ☁️ Working with **Docker, Kubernetes, AWS, Linux, Grafana, and CI/CD**
- 🤖 Exploring **AI Agents, MCP, LLM-powered systems, and agent infrastructure**
- 📚 Currently improving my skills in **System Design, distributed systems, and cloud-native development**
- 💬 Ask me about **C#/.NET, Go, REST APIs, microservices, databases, messaging, or AI agent tooling**
